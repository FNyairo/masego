# Banner images

Drop banner photographs here using these exact filenames. Each one replaces the stock
placeholder on that page automatically — no code change needed.

| File | Page |
|---|---|
| `research.jpg` | /research |
| `esg-and-ports.jpg` | /research/esg-and-ports |
| `regions.jpg` | /research/regions |
| `methodology.jpg` | /research/methodology |
| `outputs.jpg` | /research/outputs |
| `journey.jpg` | /research/journey |
| `dashboard.jpg` | /dashboard |
| `knowledge-hub.jpg` | /knowledge-hub |
| `about.jpg` | /about |
| `contact.jpg` | /contact |

Recommended: landscape, at least 2000px wide, JPEG, under ~400KB each. The banner darkens
and desaturates the image, so high-contrast photographs work best.

Until a file exists, the banner falls back to a stock image, and then to the navy gradient.
